1. @ Symbol Check Pass

Checks if the link contains an '@' symbol which ignores preceding text in browsers.

2. Length Threshold Pass

Flags links exceeding 100 characters designed to conceal the real destination.

3. IP Hostname Check Pass

Detects bare IP addresses (e.g., 192.0.2.10) instead of registered domain names.

4. Subdomain Count Pass

Flags 5 or more host segments stacked to artificially simulate legitimate authority.

5. Punycode (IDN) Check Pass

Detects 'xn--' prefixes used in homograph attacks to mimic familiar characters.

6. HTTP Protocol Check Pass

Checks for unencrypted HTTP connections that lack transit encryption.

    💡 The Core Security Lesson

    These heuristics are warning signs, not definitive proof. A link with zero flags can still be malicious (e.g. typosquatting), and a link with flags may be legitimate internal tooling. Never assume safety based solely on text heuristics.

    ⚖️ Ethical & Defensive Policy

    This tool is designed for educational cybersecurity awareness only. It performs client-side string inspection. It does not probe remote servers, extract credentials, or initiate network connections.
